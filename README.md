An original one-line pickup line written in the voice of a robot trying to
charm someone — the joke grows out of being a machine: ten thousand
simulations run, and the robot still blanks on its opening line. Machine
logic, human nerves.

`main.ts` writes the line (a single line, 96 characters) to
`/output/entry.txt`. Run it with `node main.ts`.
